# API Design

The backend uses a RESTful API powered by FastAPI.

## 1. Workspaces & Projects

### `POST /api/v1/workspaces`
Create a new organizational workspace.

### `GET /api/v1/workspaces/{id}/projects`
List all projects within a workspace.

### `POST /api/v1/projects`
Create a new project.

## 2. Core Execution (The "Cowork" Loop)

### `POST /api/v1/projects/{project_id}/goals`
**Description:** Submits a natural language goal to the orchestrator.
**Payload:**
```json
{
  "prompt": "Analyze these 500 PDFs and create a board presentation."
}
```
**Response:** `202 Accepted` with `goal_id`.

### `GET /api/v1/goals/{goal_id}/dag`
**Description:** Returns the execution graph (DAG) of tasks generated by the Goal Interpreter.

### `GET /api/v1/tasks/{task_id}`
**Description:** Get real-time logs and status of a specific task (e.g., watching the `BrowserAgent` navigate).

## 3. Human-In-The-Loop (HITL) & Approvals

### `GET /api/v1/approvals`
List all pending tool execution requests requiring user approval.

### `POST /api/v1/approvals/{approval_id}`
**Payload:**
```json
{
  "action": "APPROVE" | "REJECT",
  "reason": "Optional message to the agent if rejected."
}
```

## 4. Memory & Artifacts

### `GET /api/v1/projects/{project_id}/artifacts`
List generated files (PDFs, PPTXs, CSVs).

### `GET /api/v1/projects/{project_id}/memory/search`
Search the Semantic Vector DB for the project.
