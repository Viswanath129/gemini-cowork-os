# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0-alpha] - 2026-05-31

### Added
- **Execution Kernel**: Persistent state checkpointing and deadlock detection.
- **Agent Swarm**: `asyncio`-based worker pools for parallel task execution.
- **Shared Blackboard**: Coordination layer with promotion logic to Canonical Knowledge.
- **Observability Layer**: Tracking for Tokens, Cost, Latency, and Meaningful Work Ratios.
- **Goal Guardian**: Drift detection and re-anchoring supervisory loop.
- **Judgment Engine**: Ambiguity gates to prevent premature execution.
- **Deliverable Factory**: Scaffold for native DOCX/PPTX generation.
- **Trust Engine**: Scaffold for Claim-to-Evidence traceability graph.
- **MCP Adapter**: Scaffold for generic Model Context Protocol tool integrations.
- **Alpha Test Framework**: Logging artifacts for empirical validation (`ALPHA_TEST_LOG.csv`, `HOW_USERS_THINK.md`, etc.).

### Changed
- Shifted project focus from Task Completion optimization to Decision Improvement optimization.
