# Alpha Trial - Killed Assumptions

This document tracks the strategic learning of the project. It records the delta between our architectural beliefs and the reality of human-AI collaboration.

| Assumption | Confidence Before | Reality | Outcome |
| :--- | :--- | :--- | :--- |
| Users prefer detailed clarification | High | | |
| Users want perfect reports | Medium | | |
| Trust comes from confidence | High | | |
| Users want high autonomy | High | | |
| Speed justifies secret exposure | High | Secret management must remain local and out-of-chat to maintain trust. | Killed |

## Methodology
Every 10 missions, the lead investigator audits this list against the `SURPRISES.md` and `HOW_USERS_THINK.md` logs. An assumption is "Killed" when empirical evidence repeatedly contradicts the original architectural or product belief.
