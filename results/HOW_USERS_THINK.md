# HOW USERS THINK

This document captures behavioral insights from the Alpha Trial (First 50 Missions). 
It focuses on understanding how human users interact with an autonomous digital coworker.

## Core Behavioral Findings
- **Assumption Patterns**: What information do users consistently omit?
- **Drift Patterns**: When and why do users change their minds mid-flight?
- **Trust Triggers**: What specific system behaviors caused trust (e.g., transparency over confidence)?
- **Frustration Triggers**: What caused users to disengage or intervene?

## User-AI Collaboration Insights
- **Clarification Tolerance**: How many questions are too many?
- **Assumption Acceptance**: Do users prefer a system that "guesses right" or one that "asks first"?
- **Deliverable Feedback**: How do users react to native PPTX/DOCX vs. raw text?

## Conclusion
This dataset serves as the primary driver for the 'Preference Intelligence' layer in Phase 2.
